# Reference Genome Assemblies

This directory contains reference genome annotation metadata for TargetX analysis:
- **Homo sapiens (Human)**: GRCh38 / hg38
- **Mus musculus (Mouse)**: GRCm39 / mm39
- **Oryza sativa (Rice)**: IRGSP-1.0
- **Arabidopsis thaliana (Thale cress)**: TAIR10
- **Zea mays (Maize)**: Zm-B73-REFERENCE-NAM-5.0

> **Note**: Raw `.fa.gz`, `.gtf.gz`, and `.gff3.gz` genome dumps exceeding GitHub file size limits are automatically excluded via `.gitignore`. The TargetX runtime fetches target gene sequences directly via standard NCBI / Ensembl REST APIs.
